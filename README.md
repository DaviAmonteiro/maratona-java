# ☕ Maratona Java | DevDojo

Repositório dedicado ao acompanhamento, exercícios e anotações práticas do curso **Maratona Java**, ministrado pelo DevDojo. O objetivo é construir uma base sólida em sintaxe, lógica, estruturas de dados e Programação Orientada a Objetos (POO) em Java.

---

## 📌 Status Atual do Aprendizado

- 🚀 **Módulo Atual:** Arrays Multidimensionais (Matrizes)
- 🎯 **Próximo Passo:** Introdução à Programação Orientada a Objetos (POO)

---

## 📚 Conteúdos Concluídos

- [x] **Fundamentos Básicos:** Tipos primitivos, casting e operadores (aritméticos, lógicos, relacionais e atribuição).
- [x] **Estruturas Condicionais:** `if`, `else if`, `else`, `switch` e operador ternário.
- [x] **Estruturas de Repetição:** `while`, `do-while`, `for`, controle de fluxo com `break` e `continue`.
- [x] **Arrays Unidimensionais:** Declaração, inicialização, limites de índice e iteração com `for` e `forEach`.
- [x] **Arrays Multidimensionais (Matrizes):** Matrizes bidimensionais, inicialização direta e iteração com loops aninhados (`for` e `forEach`).
- [ ] **Orientação a Objetos:** Classes, objetos, métodos, parâmetros, construtores, sobrecarga e modificadores de acesso.
